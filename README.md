# Calculadora de Médias

Aplicação de estudos em HTML, CSS e JavaScript para registrar atividades e notas, calcular a média aritmética e indicar aprovação ou reprovação.

## Funcionalidades

- Definição da nota mínima ao abrir a página.
- Inclusão de atividades e suas notas em uma tabela.
- Verificação de nomes de atividades já cadastrados.
- Atualização da média final e do resultado a cada inclusão.

## Como executar

1. Clone o repositório:
   ```sh
   git clone https://github.com/B0nfiw/projeto_calculadora_medias.git
   ```
2. Abra `index.html` no navegador.
3. Informe uma nota mínima numérica na janela inicial.
4. Adicione as atividades e acompanhe a média na tabela.

Não há dependências a instalar nem etapa de build.

## Tecnologias e estrutura

- `index.html`: formulário e tabela de resultados.
- `main.css`: apresentação visual.
- `main.js`: cadastro de atividades, cálculo da média e manipulação do DOM.
- `images/`: imagens utilizadas nos indicadores de resultado.

## Limitações atuais

Os dados ficam apenas na memória da página e são perdidos ao recarregá-la. O projeto não possui backend nem armazenamento persistente.
